# Bank_REST — Контекст проекта

## Что это
Тестовое задание для Junior Java разработчика. Это не продакшен-проект.

## Стек
Java 17, Spring Boot, Spring Security, JWT, Spring Data JPA, PostgreSQL, Liquibase, Docker Compose, Swagger/OpenAPI

## Автор
Roman Kibenko — руководитель проекта в строительной компании, Java это второе направление. Уровень: Junior.

## Важно
- Не давать советы про продакшен-окружение (rate limiting, CORS, аудит логи и т.д.) если не спрошено
- Оценивать код с точки зрения тестового задания: чистота архитектуры, выполнение требований, базовая безопасность
- Проект разрабатывается в IntelliJ IDEA с использованием Jmix (основной инструмент Roman)

## Требования задания (для справки)
- JWT аутентификация, роли ADMIN и USER
- Управление картами: создание, блокировка, активация, удаление
- Переводы между своими картами
- Шифрование номеров карт, маскирование при отображении
- Фильтрация и пагинация
- PostgreSQL + Liquibase миграции
- Docker Compose
- Swagger UI / OpenAPI
- Юнит-тесты ключевой бизнес-логики
